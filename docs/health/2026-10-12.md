## 2. CI
**`ls -1 .github/workflows/`**
```bash
_repo-config.yml
auto-assign.yml
auto-merge-unified.yml
ci.yml
deploy-cloudflare.yml
deploy-worker.yml

sync-issues.yml

```
- `auto-merge-unified.yml`: Auto-merges dependabot and passing PRs. Trigger: `pull_request_target`, `pull_request_review`, `check_suite`, `workflow_dispatch`.
- `auto-assign.yml`: Assigns PRs automatically. Trigger: `pull_request`, `issues`.
- `ci.yml`: Runs tests and linters. Trigger: `pull_request`, `push` to main.
- `deploy-cloudflare.yml`: Deploys Astro site to Cloudflare Pages. Trigger: `push` to main (paths: `site/**`, `dishes/**`, etc). **Deploy-on-push workflow.**
- `deploy-worker.yml`: Deploys API Gateway Worker. Trigger: `push` to main (paths: `worker/**`). **Deploy-on-push workflow.**
- `guardian-agent.yml`: Auto-merge decision evaluator based on confidence score. Trigger: `pull_request_review`, `check_suite`, `workflow_dispatch`.
- `labels-sync.yml`: Syncs repository labels. Trigger: `push` to main, `workflow_dispatch`.
- `sync-issues.yml`: Syncs markdown issues to GitHub issues. Trigger: `push` to main, `issues`, `workflow_dispatch`.
- `triage-agent.yml`: Auto-labels and routes issues. Trigger: `issues` (opened, labeled).
- `_repo-config.yml`: Detects public/private config. Trigger: `workflow_call`.

## 7. Top 5 fixes
**`echo "Formulating fixes based on findings..."`**
```bash
Formulating fixes based on findings...
```
1. **Critical Vulnerability in Prod Dependencies**
   - Problem: `pnpm audit --prod` reports 1 critical and 12 high vulnerabilities.
   - Evidence: `Severity: 3 low | 12 moderate | 12 high | 1 critical`
   - Change: Run package upgrades on production dependencies.
   - Effort: M
   - Verification: `pnpm audit --prod` should report 0 critical.
2. **Broken Root Build Script**
   - Problem: Root `package.json` "build" script is just `node ./.github/readme-generate.js`. The actual site build fails if `node scripts/generate-graph.js` is run from root instead of `site/`.
   - Evidence: Running `node scripts/generate-graph.js` from root errors with `MODULE_NOT_FOUND`.
   - Change: Update root `package.json` to properly build the site by wrapping `pnpm --filter gos-site build` or fixing the paths.
   - Effort: S
   - Verification: `pnpm run build` from root builds everything without error.
3. **Vitest Agent Tests Fail Offline (ECONNREFUSED)**
   - Problem: Several `agentDomain.test.ts` tests fail attempting to `fetch` because they are relying on network instead of properly mocking the offline state.
   - Evidence: `[xavier] add queued offline TypeError: fetch failed ... ECONNREFUSED` during `vitest run`.
   - Change: Mock the `fetch` calls in tests or handle offline errors cleanly in the tests.
   - Effort: S
   - Verification: `cd site && pnpm test` runs 100% green without ECONNREFUSED errors.
4. **Deploy-on-Push Workflows**
   - Problem: Both `deploy-cloudflare.yml` and `deploy-worker.yml` deploy directly on push to `main` without waiting for a staging step or release tag.
   - Evidence: `.github/workflows/deploy-cloudflare.yml` triggers on `push` to `main`.
   - Change: Migrate to tag-based deployment adhering to the Release Tag Protocol.
   - Effort: M
   - Verification: Pushing to `main` does not trigger deployment; creating a tag triggers it.
5. **Internal AI Docs in Public Repo**
   - Problem: `docs/agent-docs/` contains AI generated session logs and reports which clutter the public gastronomic standard.
   - Evidence: `find docs/agent-docs/ -type f` lists 18+ internal AI tracking files.
   - Change: Move `docs/agent-docs/` to `.gitcore/` or `.gitignore` them, as they are not public documentation.
   - Effort: S
   - Verification: `ls docs/agent-docs/` fails (directory moved).
