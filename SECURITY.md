# Security Policy

## Supported Versions

The following versions of Gastronomic Open Standard are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| Latest  | :white_check_mark: |

## Reporting a Vulnerability

Please do not open public issues for security reports.

Instead, report vulnerabilities privately via GitHub Security Advisories by using the "Report a vulnerability" button on this repository's Security tab.

## Response Targets

- **Acknowledgement:** We aim to acknowledge receipt of your vulnerability report within 5 business days.
- **Status Update:** We aim to provide a status update within 14 days.
- **Coordinated Disclosure:** We will work with you on a coordinated disclosure timeline.
- **Bug Bounty:** Currently, we do not offer a bug bounty program.
