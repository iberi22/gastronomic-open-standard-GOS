# Scientific Analysis & Culinary Use

## Description
El queso fresco (campesino, cuajada) o salado (costeño) es omnipresente. Se come con chocolate caliente, encima de arepas o en cubos en sopas (mote de queso).

## Culinary Uses
- **Chocolate:** Se introduce dentro de la taza para que se derrita.
- **Mote de Queso:** Ingrediente principal (Queso Costeño duro).
